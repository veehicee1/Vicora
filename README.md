# VICORA

**A product of Veehicee Telecommunications and Services**  
**Positioning:** Premium international education technology platform  
**Tagline:** Education Without Boundaries.  
**Market:** Nigeria first, then international markets.

## Product family

- **VICORA School** — school management and administration
- **VICORA CBT** — examination delivery, question banks, marking and results
- **VICORA Learn** — e-library, curriculum, schemes of work, lesson notes and practice
- **VICORA Admin** — platform and school administration
- **VICORA Parent** — parent portal and communication
- **VICORA Analytics** — reports, broadsheets and performance analysis
- **VICORA AI** — curriculum-aligned educational assistance
- **VICORA Host** — Android/local examination hosting and synchronisation
- **VICORA Desktop** — Windows administration and examination applications

## Repository status

This repository is the independent VICORA project. The original private repository `sheggun1/CBT-GTMC` remains untouched and is still the authoritative reference for existing CBT functionality.

The initial project package was assembled from saved reference files. **The full latest source tree has not yet been imported.** Do not treat this repository as a complete or production-ready application until the full source, tests, workflows and platform components have been recovered and verified.

## Preservation and security rules

1. Keep the original CBT repository unchanged.
2. Preserve existing features, data structures and historical workflows during porting.
3. Do not commit student/parent production data or credentials.
4. Keep secrets in GitHub/Vercel/hosting secret stores, never in source files.
5. Implement changes incrementally and test each module before release.
6. Do not deploy to production without explicit approval.

See `docs/ARCHITECTURE_AND_MIGRATION_BLUEPRINT.md`, `docs/MIGRATION_CHECKLIST.md` and `docs/VICORA_MODULE_REGISTER.md`.
